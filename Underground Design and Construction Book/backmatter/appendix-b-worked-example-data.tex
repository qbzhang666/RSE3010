\chapter{Worked Example Data Sets}
\label{app:datasets}

The worked examples in the main text draw on a small number of consistent data sets, collected here so that every calculation in the book can be reproduced and varied.

Four sets are provided. The first is a sandstone rock mass with the intact properties, Geological Strength Index range and disturbance factor used in the parameter derivation of Chapter~\ref{ch:rock-mass-parameters}. The second is a deep tunnel at 650\,m depth with the stress field, rock mass parameters and support properties used in the convergence--confinement example of Chapter~\ref{ch:ccm}. The third is a shallow urban alignment with the soil and rock profile, volume loss assumptions and building geometry used in the settlement and damage assessment of Chapter~\ref{ch:settlement-damage}. The fourth is a set of borehole logs with core recovery, $\RQD$ and discontinuity records supporting the characterisation chapters.

Each set states its provenance and the extent to which values have been rounded or idealised. None should be used as design input for a real project.
